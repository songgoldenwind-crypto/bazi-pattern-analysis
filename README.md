# 八字格局分析

`bazi-pattern-analysis` 是一个用于分析八字格局与喜用神的 AI Agent Skill。接收已有四柱，以内部规则说明月令取格、成败救应、相神、旺衰、调候及取用条件。

## 分析内容

- 月令取格：本气不透、余气透、多神并透、杂气取清、合会变格与主次舍取。
- 成败救应：官、财、印、食、杀、伤、禄劫、阳刃各配法，以及成中带败、救而不尽、路径改换。
- 相神：区分成格之相、护相之救与一般喜神，指出具体干支、职责和可用状态。
- 旺衰：结合时令、根气、党势及生扶克泄，评估日主与关键十神。
- 调候与喜用：十日干十二月支共 120 项条件规则；区分气候、材性与格局职责，排列首需、辅助及条件性需要。
- 特殊格与岁运：真从、假从、从旺、从强、从儿、专旺、化气与两气成象；复核给定岁运的补根、损相、救败、变格与喜忌变化。

完整命盘分析分别交代格局成败、相神、旺衰、调候和综合喜用。规则包含成立条件和失效条件，不以五行数量或缺失直接决定喜忌。

从格分析区分“藏有根气”“根能发挥”“足以支持普通生扶制化”；半合助势与完整合化分别核验。食伤对官杀有所制约，可以是假从的残病，并不自动等于普通食神制杀已经成立。

## 安装与调用

对于支持加载 `SKILL.md` 的工具，将本仓库作为一个完整的 skill 目录安装。保留 `SKILL.md`、`references/` 与 `agents/` 的相对位置。

Codex 的本地安装示例：

```sh
mkdir -p "$HOME/.codex/skills"
git clone https://github.com/songgoldenwind-crypto/bazi-pattern-analysis.git "$HOME/.codex/skills/bazi-pattern-analysis"
```

调用示例：

```text
使用 $bazi-pattern-analysis 分析我提供的四柱。
四柱按年、月、日、时排列，请分别说明格局成败、相神、旺衰、调候及综合喜用，并解释决定结论的作用路径。
```

## 输入与范围

输入为已经排好的年柱、月柱、日柱、时柱。分析岁运时，另提供已有的大运、流年及所问时间范围。本 skill 不计算历法、四柱或起运岁数，不包含排盘代码。

本仓库只包含重新整理的条件规则、命例演练和必要的技能文件，使用时无需外部书库，不包含原始资料或逐页摘录。调候按日干分为十个文件，每个收录十二月支，按需读取对应项。

提供 22 组完整四柱及 4 组给定岁运演练，用于检查推理路径、反例和条件变化。规则覆盖不等于穷尽所有命局，也不表示预测准确率已获验证；决定性效力未定时保留具体分支，不因反复追问改变判断口径。
