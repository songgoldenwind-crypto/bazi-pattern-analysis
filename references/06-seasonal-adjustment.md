# 寒暖燥湿与月令配合

## 调候与其他取用的关系

月令格局与气候互参。调候可能不可缺，但不一定独自承担实际主用；所需之神还要有根气，能参与配置，并避免反过来破坏主链。

区分两种职责：一是寒暖燥湿的改善，二是日干与月令的材性配合。夏冬的寒暑需要通常较突出，春秋仍可能有余寒、燥湿问题；庚金需要火的锻炼、厚土需要木的疏通等配合，也不能全部解释成取暖。

## 判断流程

1. **看季节与实际配置。** 冬月不等于水势必旺，夏月不等于日主必旺。结合支中火水、湿燥土、根气和透干判断；节后深浅未知时不臆定上半月、下半月的专门条件。
2. **说明气候影响谁。** 是寒木水印难以发挥生机、金水太冷、火炎木燥，还是土燥妨碍生金。避免只有太寒、太燥标签，没有作用对象。
3. **按内部规则提出候选。** 分别说明温暖、解炎、润燥、去湿或材性配合的职责。下列月令细则仅用于提出候选，不直接裁决最终喜用。
4. **核验效力。** 查气根、生源、克制、合绊及位置。虚浮之火与通根之火、泛滥之水与有源可用之水不同；藏支不能冒充已经清透。
5. **合并格局和扶抑。** 判断它是首需、兼用、辅助，还是会破坏更关键的配置。已有适度配置时不再机械增加，只有需要而未具备时说明缺口。

## 通用气候分支

| 情况 | 可考察的改善方向 | 失效条件 |
|---|---|---|
| 寒重、火弱 | 有根有助之火提供暖气 | 火虚浮受制，或寒湿成势而一点火不能参与；不能仅见丙丁便称已暖 |
| 火炎、燥热 | 有根有源之水解炎，配合金源 | 水受土克、被合牵制或无源无根；偏极火势须先核验顺势结构 |
| 木燥、土燥 | 适量水润泽，检查能否到达所需之处 | 水反而冲坏根援、损火过重，或仅有一字而不能发挥 |
| 湿重、寒湿 | 火暖、燥土等改善候选，分别核验 | 土反埋金、壅水，火受湿势压制，不能按一个五行名字保证改善 |
| 温润已有适度配合 | 保留现有配置，以格局与力量的首要问题取用 | 再增所谓调候神反致过量，或破坏官印、制杀等主链 |

辰丑偏湿、戌未偏燥，但实际燥湿仍看全局。四个土支不能作为完全相同的生克材料；同一土既可能润养，也可能埋金、晦火或壅水，需落实具体条件。

## 已收录的月令候选

以下是部分月令的条件规则，不是十日干十二月的完整专用矩阵。

| 日干月支 | 候选及职责 | 必须核验 |
|---|---|---|
| 甲、寅月 | 丙参与初春暖局，癸参与滋养，分别检查是否有需要 | 甲根、寒暖实况、火水是否过量；不能要求每个甲寅盘都凑齐丙癸 |
| 甲、巳月 | 癸提供润泽，庚参与金木配合 | 火势、水源、庚的力量及制约；不能把庚只理解为身旺便克木，也不能把此候选覆盖所有巳月条件 |
| 庚、辰月 | 丁参与炼金，甲参与疏土 | 土是否真厚、金火强弱、丁甲是否可用；不能推出所有庚日都必须丁甲 |
| 辛、寅月 | 己生金、庚扶金、壬泄秀，按需要分别核验 | 辛失令后的根援、土是否埋金、壬是否泄过及寒暖；不要求三者一齐增加 |
| 癸、寅月 | 辛或庚提供水源，丙参与暖局 | 是否缺源、寒暖是否适宜，丙辛相合是否影响职责；同见丙辛不等于已经化水 |

## 丁火寅月

甲印当令，先查甲能否生丁、丁有无根气与附丽。分开看三种配合：甲提供生源，庚参与裁印与金木火配合，水适量润木。不能把三种职责压成甲庚壬缺一不可，也不能把金水候选都视为越多越好。

- 甲有根而丁能承生，不等于还需不断增甲；甲过多而火难发用时，再考察裁印、劈甲的需要。
- 庚藏与庚透分开，辛不能自动替代庚在该材性配合中的全部职责。
- 水少可润，水多可能湿木伤火；水的官杀作用与润泽作用须分别评估。
- 已有巳等火气可以提供温暖，不因寅月仍有余寒就机械再增火。
- 印格已有食神泄秀、财承接等主链时，先核验该链，再判断这些候选是否有助，不能用月令候选推翻实际需要。

## 丁火午月

丁得禄，仍先查实际根援、克泄及是否身旺火燥。身旺而燥热时，壬水是解炎的重要候选，金可提供水源；不能仅凭丁火需要木生便继续添木。

- 壬已出现不等于调候完成：须查水根、金源、土克及丁壬相合后的效力。
- 水无根、金源受旺火压力时，记为所需已有其字、效力尚待支持，不能称水火已充分调和。
- 日主合官在格局上不必视为官被合去，但相合可能牵制其调候效力；两项判断可以同时成立。
- 财生官与金生水源可以由同一字承担，相神与调候辅助不必硬拆。
- 土有合杀取清等救应职责，不等于所有土都有利；土重克水仍可能破坏所需。

## 丙火辰月

辰月丙火有向旺的季节趋势，不等于具体日主已经身旺。分开评估火的支持、水的实际强弱及土是否厚重，不能固定“丙辰必再用壬甲”。

| 实际条件 | 可用方向 | 限制 |
|---|---|---|
| 火有根援、能任官杀，水不足而需要调济 | 壬水参与水火配合；水缺源时再查金能否生水 | 已水重火弱，不照用；金生水会否反成财党杀另验 |
| 土厚晦火、壅水，木能发挥 | 甲疏土、护所需水，并可生火 | 甲须有气可用；被金伤、合绊则不能只按木克土保证疏通。乙不自动承担甲的全部材性职责 |
| 水势已强、日主普通身弱 | 有力之印承水生火；土制水是另一候选 | 印须能承生；用食土须身能承泄、土有力。若符合从格，转顺势分支，不强用印比或土逆制 |
| 土重、无可用甲，火旺而水弱 | 可比较金泄土并生水的替代路径 | 身弱杀重时金反可能党杀，不能把庚当作甲的无条件替代 |

同一甲木可兼疏土与化杀生身，须分别解释两个对象；已有水过量时，不因月令取水的候选规则继续增水。戊土出现也不保证制水成立，湿土根的条件见 [01-chart-and-strength.md](01-chart-and-strength.md)。

春月水重可说湿、火难发挥，但不能直接称冬季严寒。季节气候与官杀旺势分开描述；火无根不能仅凭数个丙丁便认定暖局充足。

## 使用限制

冬金见火时，暖局与扶身分别判断；金水泄重而身需根援时，不能以暖局取代扶身。夏木用水印可兼润泽，也不代表所有身强夏木都必须放弃泄秀。

未收录专门月令细则时，仍可按本文件的通用分支说明寒暖燥湿及已有配置，明确这是一般气候判断；不补造固定的月度用神顺序。偏极结构先看是否能承受逆势之神，不能以象征性的一点水火宣称已调候。
