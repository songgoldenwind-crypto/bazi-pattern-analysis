# 寒暖燥湿、材性与逐月取用

## 判断流程

1. **看季节与实际配置。** 夏冬寒暑通常突出，春秋仍有余寒、燥湿；冬月不等于水势必旺，夏月不等于日主必旺。节后深浅未知，不编造司令或上下半月。
2. **说明影响对象。** 寒湿是否使木难生火、金水难发挥，火炎是否使木土焦燥、金水受伤。不能只有“太寒太燥”而没有作用路径。
3. **区分气候与材性。** 暖、润、解炎、去湿属于气候；炼金、裁木、疏土属于特定配合。逐月候选含两者，不把庚裁甲解释成温度调节。
4. **只查对应日干、月支。** 读下面一个日干文件的相应月份，提出候选、转向、失效条件；不要给每盘机械堆一张十二月表。
5. **核验效力。** 根气、生源、合克、位置及过量逐项检查。原局有火字、火能暖、足以改变寒湿是三层；水同理。
6. **与主链合并。** 调候是否首需、兼用或已有适度配置，依 [综合排序](05-useful-gods.md) 裁定。相神被破、日主无法承受时，不能只凭月表宣布喜用成立。

## 通用气候分支

| 实况 | 可比较的改善 | 失效与过量 |
|---|---|---|
| 寒重、火弱 | 有根火暖，木能引火，必要时护火约水 | 浮火受压、湿木无焰；火过强又克弱金、泄弱木 |
| 火炎、燥热 | 有源水解炎、金能立足供水源 | 水无根受土克、金受火伤；偏极结构一点逆水可能难立 |
| 木土干燥 | 适量水润，疏通妨水之土 | 水难到达、反坏根或灭唯一火；水已有足润不再增加 |
| 寒湿、泥重 | 火暖、有效土约水或其他疏泄，依病处定 | 湿土未必止水，土也可埋金壅水；没有固定“见湿加土” |
| 温润已适度 | 保持现有配置，转看格局与承受的首需 | 再增调候神可能过量或破官印、制杀等链 |

辰丑偏湿、戌未偏燥是起点，实际仍看水火透藏、时令与党势。不能把四土当相同材料，也不能由土制水弱推导该支所有藏气消失。

## 替代与冲突

丙丁、壬癸等可有重叠职责，但合对象、根源、力量和材性不同。说明替代完成哪项功能、缺哪项功能，不自动等效。丁有根且寒而不泛水时可以持暖，寒湿极重时未必足以承担解冻；不能把“不足”写成“一点作用都没有”。

冬金需火而泄弱，火保调候职责、金土根援保承受，可以兼顾；火既克身又暖局，须限量并保根。夏木火泄太过，水印润木不必视为必然夺食；但水多灭唯一泄秀火时仍损主链。

特殊格先查资格及逆势之神能否立足，不能以温度标签强推相反喜用。月令 120 项覆盖的是候选和条件入口，并非所有八字组合的穷尽证明；出现未列的交互时，依内部力量、合冲和主链规则展开，不凭记忆补口诀或到外部书库取结论。
