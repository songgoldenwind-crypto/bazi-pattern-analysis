# 术语与判断口径

## 默认方法

按“月令候选 → 成败与相神 → 实际力量 → 气候与流通 → 综合取用”组织判断。月令说明格局从何而来，成败说明配置是否成立，旺衰说明相关各神能否承担职责，调候说明寒暖燥湿是否妨碍配置。

普通结构使用这条主线；遇到从、化、专旺等偏极证据，转入对应内部规则，不强令特殊格服从普通扶抑。用户指定不同方法时，先说明采用的定义及成立条件，保持同一次推演的口径一致。

旺衰用于判断谁能任职，不能预先替格局确定谁应被保护或制约。身旺能任泄，不等于食伤必为首用；印会生身，也不等于身旺时它的制伤、护官职责必然多余。相反，传统善恶分类不能直接决定现实吉凶，也不能省略制、化、泄各条配法的比较。喜忌反向的候选按 [配法比较](13-competing-configurations.md) 裁定。

## 同名异义

| 术语 | 本技能的含义 |
|---|---|
| 月令格局用神 | 日干配月令所得的格局出发点，包括财、官、印、食、杀、伤及禄劫刃等背景；有的须顺成，有的须制化，不等于越多越好的有利之神 |
| 相神 | 使格局主链成立的关键辅助，承担生、护、制、化、合或解冲等职责；不能固定等于某一种十神 |
| 喜神 | 有利于当前目标的神，必须说明它支持哪条路径；不把所有喜神都称相神，也不把有利五行视为永远有利 |
| 扶抑用神 | 解决日主或关键十神的太过、不及；不能仅凭身弱便固定用印 |
| 病药用神 | 针对破坏成局目标的具体障碍取药；病可能是关键神受损、相碍、过度或不及，不只指身弱 |
| 通关用神 | 能引通两方争克的中介，须有实际根气和作用通路 |
| 调候用神 | 改善寒暖燥湿的配置；与日干材性配合分别说明，不把所有月令候选都解释成升温或降温 |
| 忌神 | 在当前条件下破坏关键配合的神，不能按十神名称永久分类 |
| 闲神 | 对当前关键问题作用较轻的神，随岁运或主链变化仍可能转为关键 |

同一字可以承担多种职责。例如月令为印，食神承担泄秀兼暖局：印是格局出发点，食神可为相神，同时又是实际取用。名称不同不等于结论相反。

禄劫要分别记录“月令背景、另取所用、成局辅助”。例如禄格另取伤官而生财，伤官为另取所用，财承担接续；若取官而以印制伤，官为所用、印为护官之相。仅以禄旺得泄的口径称食伤为辅助时，应写明它辅助的是哪条路径，不把扶抑所喜直接改名为已成立的相神。

## 分歧如何处理

1. 先查定义。月令七杀为格局用神、食神为制杀相神，与把食神称为实际用神可以相容。
2. 再查条件。身强杀轻与身弱杀重、印有根与印受财破、火有根与火虚浮，不应得出同一结论。
3. 定义和条件相同仍有分歧时，说明本次选定的规则及理由，另列会改变结论的分支，不按说法数量投票。
4. 未列入包内的专门标准不能冒充已知规则；保留候选及缺失条件，不让读者另找外部资料才能完成当前推理。

以下分支须明确处理：

- **杂气与冲库：** 默认判断具体藏气、透干和冲的损益。少量冲刑引动藏气，只能在该气原先确实受束、冲后没有损坏关键根援时作为候选，不把冲库视为成格前提。
- **从格的严格排除与效力判断：** 默认按 [从格判定](10-following-pattern-decision.md) 逐项检查根、印比和逆神。弱印、食伤等可使从之不纯而进入假从，不一律否从；有力之印实际化杀生身则是普通结构的重要证据。用户明确选择见印、见食伤即排除等严格标准时，单列该标准下的结论，不暗中切换。本包不单凭所从之神未占月令就定义假从。
- **专旺见官：** 默认先看官杀能否逆转主势及有无顺势流通，不能仅凭出现一个官杀字就定成败；也不能把普通官格的喜用直接移来。
- **十二长生：** 生旺死绝可作辅助信息，不能替代地支实际藏干、同气根、时令及生扶克泄。一个死绝标签不等于没有根气。

## 固定采用的判断口径

- **主格与配法分层。** 月令印格而用食泄秀，主格仍为印，配法为印用食；不因最终喜食便倒称食神格。月令合会确实改向，才另论变化；原月令的季节背景仍在。
- **正偏不抹平，也不按名判吉凶。** 官杀涉及取清，食伤对官的关系不同；正偏印都可能生身，只有实际夺食时才论枭夺食。不能把见偏印等同于夺食。
- **作用有程度。** 合、冲、制、化分别区分关系存在、部分牵制、足以改变主链。没有固定的合冲优先级，也没有一字抵几字的数值。
- **气候与材性分开。** 暖局、润燥属于气候；炼金、疏土、裁木等是特定配合。逐月文件中的候选不全是调温之神，须说明实际职责。
- **从儿采用提纲成势而顺生的口径。** 不以日主无根为必要条件；食伤须主导、财须接续。食伤与月令本余气及月支参与的方局均无有效联系，只在他柱独旺时，列扩展口径候选，不冒充默认已成。
- **化气从严确认。** 对合涉及日主只是入口；化神成势、原气不能自立、无有效争破才可改按化神取用。普通天干合绊不称化气格。

## 证据层次与稳定性

每次把三个层次分开：**事实**（四柱、透藏、实际合冲组合）、**效力判断**（哪一根可靠、哪一克制够用）、**结构结论**（何格、成败、喜用）。有字不等于有力，有力不等于足以完成某项职责。

重问同一盘时沿用已列事实和口径。新增四柱、岁运、节令信息或发现推理错误，才修改对应节点，并说明修改理由。不能因用户追问“到底”就把原先有条件的判断改成确定事实。

若两种解释都能容纳同一事实，选证据较直接的一条作主判，并指出分支具体改变哪一项喜用；无法排定时保留两支，不能用虚构概率填补。现实经历仅用于辅助复核，不以人物身份、财富或事件结果倒造规则。
