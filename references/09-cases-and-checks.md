# 机制示例与反例复核

以下以条件组合说明判断机制，不对应人物经历，也不作为预测准确性的证据。条件改变时，结论须重新核验。

完整四柱与给定岁运演练另见 [12-worked-cases.md](12-worked-cases.md)，不可将这些机制条件当作已经给出完整命例。

## 冬金需要火，不等于主用一定是火

辛金生冬月，水食伤泄气，局中火有根可参与暖局；若日主受泄后仍需根援，金根可以承担扶身需要，火保留调候职责。

**检验点：** 同时说清暖局与扶身。仅凭冬金喜火就断火是唯一用神、金一律为忌，会遗漏承受条件。反之，若金根已足而寒重，也不能继续只谈扶身而不顾气候。

## 印格不是只能喜官生印

甲木生冬月，印旺而木有多处有效根援，食神火可以泄木兼暖局；官再生印未必改善首要问题。

**检验点：** 月令印格与实际取食并不矛盾。该路径需要身能承泄、火能发挥；不能泛化成所有冬木都忌金水，也不能把身弱印轻的盘照此处理。

## 从儿不能机械套身弱无根的门槛

水日主生木月，食伤得令成势，又有火财接续时，可核验水生木、木生火的从儿路径。水比劫能顺生木，不因其出现就套用从财从杀的排除门槛。

**检验点：** 比劫若又争夺所需火财，仍要处理该病；允许比劫参与顺生，不等于比劫永远为喜。食伤未成势或财不能接续时，也不能把普通食伤生财升级为从儿。

## 偏极不是一般身旺再加克

火生夏月，印比与火根集中，一点无源无根的水未必足以制火。此时应核验是否已偏极、逆制能否奏效及顺势路径是否成立。

**检验点：** 先判断水的实际力量及有效逆神。既不能因有水便称已经平衡，也不能由火多直接宣布从强；若水有根有源、足以逆转主势，需回到普通结构重新评估。

## 有印比，比较能否依靠

官杀成势，日主无同气支根，只见浮比、藏余气印；若印比孤弱，生扶被强势压制，仍不能自立，应核验假从，不因有印比直接否决。改变条件：印得强根、有生源且能转杀生身，便有普通身弱用印的依据，即使日主依然弱，也不能继续强判从杀。

**检验点：** 从格资格看实际依靠，真假还看清纯；印字存在、印得生、印能化杀生身不得合并成一步。

## 湿土有藏根，不等于能够止旺水

旺水成势，戊土仅依孤立辰湿土，无火暖燥、无其他坚实土根时，先查土是否随水而弱，不能以辰藏戊便证明制水有力。改变条件：戊另有稳固燥根或火土支援，且支持未受重损，其制水作用就不能忽略。

**检验点：** 前者不是“辰永无根”，后者也不是“土一出现即制伏水”。两者都还须查制约程度和日主承受，才能确定格局与喜用。

## 食伤破从杀清纯，不等于已经能按普通制杀立局

日主无可依靠的支持，官杀仍主导，弱食只有部分制约时，可以是假从官杀带病。财若有根且能引食生官杀，才有去病通路；没有可用财，不能把此通路记为原局已经成立。

改变条件：日主有可用根援、能承食泄，食有力且与杀配合，才有普通食制杀的依据；若食杀两方各成强势，则另查从势和争战，不能用同一条结论套用。

**检验点：** 排除真从不等于排除假从，制约关系存在不等于制化成功，也不因假从带病就取消全部作用分析。

## 半合有势，保留各根的单独判断

子辰半合、透水且水另有根援，可以增强水势，即使申未出现。不能虚填申，也不能以缺申为由认定水不能成势。辰内土木的作用另查，不因水势强一笔删除，亦不因未成完整三合就给全部藏气足额效力。

**检验点：** 组合完整、气势主导、全支成化是不同结论；其中任一成立，不自动证明其余两项。

## 同为丙辰月，助水与化水生火可能相反

火有根援、水弱而土厚时，可以比较木疏土护水，或在身能任杀的条件下金泄土生水。改变条件：水已强、火弱时，再用金生水可能党杀；先比较木能否承水生火，并核验是否属于从格。

**检验点：** 月令细则用于提出条件候选，不能覆盖强弱、从格及通关效力；原局只有藏乙也不能冒充甲清透。

## 条件对照

| 常见误判 | 必须复核的分支 |
|---|---|
| 月令七杀就是越多越好的喜神 | 分格局用神与实际喜神；查制化、身杀力量及杀是否已经过弱 |
| 食神制杀见印必坏 | 印是否真夺所用食、是否转成杀印、是否另需调候且不碍原链 |
| 印格见财必坏 | 印轻或重、身强弱、财印位置、财抑其过还是破其所需 |
| 杀有食制，再加财总会更好 | 财是否泄食党杀；制过杀轻等条件才可能需要护杀 |
| 建禄就一定身旺 | 根援、受制泄与全局气势；月令标签不能替代实际力量 |
| 身旺印重，必以食伤为相 | 核食伤效力及印是否制伤护官；按 [竞争配法](13-competing-configurations.md) 比较后命名相神 |
| 官藏而不透，不能取用 | 查根源、生护和救后职责；也不能只因有藏官就固定护官为主 |
| 印制伤只能用于身弱 | 分制伤扶身与制伤护官，护官还须防印重泄弱官 |
| 有根且能生财，就已成泄秀生财 | 先证食伤可发挥，再证财能承接；藏财各项作用不能重复满额计算 |
| 有根、有印比便一定不从 | 根的实际支持、印能否化生、比劫自身有无根；区分假从残病与普通格根援 |
| 戊见辰便足以制旺水 | 湿土承载、火燥土援助、水势及所需制约程度；不把藏干身份当成功效 |
| 有食伤制官杀就排除全部从法 | 是否只破真从清纯，还是已建立可依靠的普通制化；假从带食伤之病另论 |
| 半合不齐所以完全不起作用 | 旺支、透干与党势；可助势不等于虚填缺支或全部成化 |
| 缺火就补火 | 是否真需要火、具体职责、会不会破官坏印或逆旺 |
| 丙辛同见就化水 | 相合与真化分开；查时令气势、根苗及破坏，日主化格另验 |
| 辰戌冲就开财库 | 库中哪个十神、冲后是否得用或损根、有无其他破坏 |
| 春秋不需要调候 | 余寒、燥湿和实际配置仍要判断；材性配合也不能全归寒暑 |
| 从儿有比劫就不成 | 查食伤提纲、财的接续及比劫顺生还是争财 |
| 同是水运就都吉 | 运干运支、根气、所生所克所合对象与原局路径分别核验 |
| 缺时柱就完全不能判断 | 可分析月令候选与现有三柱条件，说明时柱可能改变根援、救应及特殊格资格 |

## 输出前复核

回看自己是否回答了格从何来、成败因何、用解决什么、凭何有力。然后检查：

- 同一用神是否中途换义，是否把相神、调候和月令格神混成一个集合。
- 是否只数五行、只看得令、只见字而未查根气及位置。
- 是否把“根未证消失”当作“根已证有力”，或把“不够制伏旺神”当作“完全没有逆作用”。
- 从格争议是否分别比较真从、假从、普通结构；喜用相反时是否先解决决定分支的根援问题。
- 是否同时认可互相破坏的两条主链，遗漏救应带来的新病。
- 有竞争配法时，是否以同样的对象、效力和副作用标准比较，交代另一条的具体断点；是否因用户偏好就把另一分支升级为已证结论。
- 是否把待运之神当成原局已有，把合冲关系当成必然结果。
- 相神失用后是否重评主链，是否漏掉护相之救受伤；喜用是否列出首需与条件，而非无条件五行集合。
- 逐月候选是否对应真实日干、月支，是否把材性误当气候、把需要误当已经做到；得生与承生是否分开。
- 岁运是否保留原局基线，再评补根、损相、争合及资格变化；是否沿用已经过量的旧喜神。
- 完整分析是否分别交代格局、相神、旺衰、调候和综合喜用；规则未穷尽的交互是否如实限定结论。

只修正会改变结论的遗漏，不为每次简单问答扩写整套报告。
