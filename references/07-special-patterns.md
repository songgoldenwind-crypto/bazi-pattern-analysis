# 从、化、专旺与从儿

特殊格的判定必须说明所用规则、成立证据与否决条件。没有证据时保留候选；不能因普通扶抑难以选用，就称“从格所以反着看”。

## 从财、从官杀、从势

遇到从不从、真假从争议，读 [10-following-pattern-decision.md](10-following-pattern-decision.md)。先确定主势，再逐项核验日主根、印比与逆神的效力，比较普通偏弱、假从和真从。

真从要求日主无可依靠的生扶且顺势清纯；假从允许浅根、浮印比或轻微逆作用残存，但日主仍不能自立。食伤破官杀可以是假从的病，不能因存在食伤就把全部从法一并排除。有力之印确能化杀生身、根比可以依靠时，才构成实际否从证据。严格排除法与效力判断法须分别说明。

从财、从官杀、从势以实际主导力量和流通去向区分；从神自身也有太过、不及及寒暖燥湿，不能把顺势简化为永远增加同一五行。

## 从旺、从强与一行专旺

本包区分从旺（比劫势重）与从强（印比重重、气势偏极）。在印很重的从强结构中，食伤可能被强印制，不能照抄从旺顺势泄秀的路径。财官逆旺的风险也须落实到实际力量和通路，不依据一个字定灾。

曲直、炎上、稼穑、从革、润下通常对应木、火、土、金、水一方成势。需核验：

1. 日主与局势的关系，时令及方局是否支持这一气势。
2. 印比、泄秀、财之间能否顺势流通，是否存在有效逆神。
3. 寒暖燥湿是否使气势虽偏一方却难以发挥。
4. 是确已偏极而顺势流通，还是仍有有效逆神、需要回到普通格重新取用。

不能把五格压成一张永久喜忌表。官杀若有根有力并能逆转主势，应重新核验特殊格资格；无力浮露又不能算已经制伏旺势。五格名称只表示候选，不是已经证明成格。

## 从儿是单独分支

从儿要求食伤在提纲成势，并有财接续，构成“日主 → 食伤 → 财”的流行。其判定不单凭身强弱，不能套用从财从杀必须日主绝无根援的同一门槛。

检查食伤是否真成势、财是否接上、比劫能否顺生、有无印破食伤或官杀引起争战。比劫并非永远是喜：若具体比劫夺走所需财，仍须找有效制合。格名不能取消局内具体作用。

不能把任何“食伤生财”普通格都升级为从儿；月令、党势和流通证据不足时，仍按普通食伤财结构分析。

## 化气

1. 明确是哪一对五合，是否涉及日主，是否真有合化之势。
2. 查化神时令、局势、根气，以及原气根苗、其他天干是否实际阻碍。
3. 合而不化时仍按原五行分析合绊、牵制与生克，不把全局剩余干支一律改成化神。
4. 真化后也须辨化神有余不足：有余考察泄秀，不足考察助成，不能简单“化土所以火土永远喜”。
5. 假化另查病及去病条件，不因有一个对合就宣判真化，也不把真假化古例的品行断语当现实事实。

见辰不等于化气成立。月令对化神的支持、全局成势及原气能否继续自立需要合看，不能以单一地支或一条月令对应表裁决。合后仍有有力原气根援、争合妒合或克破化神者，先保留合而不化或假化候选；证据不足不宣布真化。
