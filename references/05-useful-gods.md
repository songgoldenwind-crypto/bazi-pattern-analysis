# 喜用神的选择与取舍

## 先写问题，再取药

不要从“五行缺什么”出发。先完成三句话：

1. 月令起点及当前可成立的主链是什么。
2. 关键障碍是什么：力量不及、过度、关键神受伤、两神争克，还是寒暖燥湿使配置失效。
3. 哪一个具体神能解除障碍，它现有的根气、位置和援助能否做到。

先核实是否属于从、化、专旺等偏极结构；若确属偏极，不把普通旺抑弱扶硬套其上。真从、假从与普通身弱的比较见 [10-following-pattern-decision.md](10-following-pattern-decision.md)。若不同方法指向不同字，不预设一张对所有命局有效的“调候永远第一”或“扶抑永远第一”顺序表。

## 五条取用路径

| 路径 | 判定需要 | 必须核验 | 常见错误 |
|---|---|---|---|
| 扶抑 | 日主或月令关键神有太过、不及 | 是哪一方失衡，生扶、制、泄是否真能补救 | 日主弱一概印；旺一概官杀；将克泄耗当固定分数 |
| 病药 | 已有有益路径被某神破坏 | 药能否去病，去病后主链是否恢复，是否又带来新病 | 先固定某字为忌，再倒找理由；凡受克都称病 |
| 通关 | 两方争克，能引通者有实际作用 | 中介有无、能否接上、是否被克合或隔断 | 有一个相生字就宣布通关；局无中介却说原局已通 |
| 调候 | 寒暖燥湿显著影响全局所需 | 调候神有无气根、能否参与、会否破主链及自身是否过量 | 冬天一律用丙；夏天一律用癸；照表圈字即完成判断 |
| 顺势 | 真从、假从、化气、专旺等结构已通过相应条件核验 | 所从/化的气势及其有余不足；假从另查残病与去病路径 | 见偏旺就叫从强；一律越旺越好；有一点逆作用就排除假从；见五合就取化神 |

这五条是组织判断的路径，不能代替每条路径的成立条件。普通结构与特殊格须先区分，不把一张分类表当成自动选用神的公式。

## 常规扶抑的具体分支

以下只适用于未确认特殊格的普通结构，仍须结合月令成败：

- **身弱杀重**：优先比较印化杀生身、比劫帮身或食伤制杀能否成立。印有根能承接者与浮印被财破者不同；身已不能任泄时，不能只因食克杀就认定食制最优。
- **身弱财旺**：比较比劫分担与印生身。财能坏印时，不能机械先选印；比劫有根亦可能更切需要，但也须防群劫争财无食伤引通。
- **身弱食伤重**：印能制泄生身，可成为需要；若正采用从儿路径，须先检验该路径，不能直接套这一条。
- **身旺印多**：可取食伤泄秀或财抑印，分别核验；印格已有合宜泄秀时，不因“财能制印”就再加财破坏现成配合。
- **身旺比劫多、财轻**：食伤引通生财常比直接加一弱财更能成链。官杀可否制劫，须查其力量及食伤是否反攻官杀。
- **身旺官杀轻**：财可滋官杀；若已有食神制杀且制过，须辨是护杀还是转向其他路径。不能永远以官杀受制为喜。
- **身杀均衡且食有力**：食制杀可能合宜；若再透印夺食或财泄食生杀，需复查平衡和救应。

这些分支需要全局证据，不是仅凭“身弱/身旺”两个字即可选定用神的自动表。

## 通关如何证明

常见五行中介：金木争克用水引通，木土用火，火金用土，土水用金，水火用木。具体到十神，还需写成杀印相生、财官相生等实际链条，判断被引通的两方是否确实有这种需要。

每次写清“哪方 → 中介 → 哪方”，并确认三者力量及通路。原局没有中介时写“有此需要而原局未具，待某运再论”，不能把需要与已经具备混为一谈。

水火之间取木，须证明木能承水而生火。木有根、得援而未被金伤、合绊等破坏，与孤弱木受寒湿浸困不同；水已过旺时，不能因水生木就假定木越得水越有力。只有辰中木余气时，记清藏气及支持条件，不能直接当作甲木清透、通关完成。

原局若按从官杀取用，木印泄杀生身可能成为逆势因素；按普通身弱取用时，同一木印可能是关键救应。遇此相反取舍须先裁定从格分支，不能直接汇总成“水木火都喜”。

## 多种需要发生冲突

例如食神制杀格，印既可能生身化杀，也可能克食损制杀：

1. 先判食制杀原路径是否已足且为全局所需。
2. 若身弱杀重，印化杀是否确能接替该路径；不能一边说食被夺，一边仍按食制成功评价。
3. 若印只需轻用调候或有财制、位置不相碍，说明成立条件，不扩成“食神永不忌印”。
4. 若两条都不充分，保留不足，不凑一个听起来完整的格局名。

调候与扶抑冲突同样处理：调候参与配置所不可缺，未必就是承担扶身/抑强的唯一主用。具体反例见 [案例](09-cases-and-checks.md)。

## 喜用记录格式

相神的职责与可用性另见 [11-xiangshen.md](11-xiangshen.md)。先说明主链，再填相神，不能把所有有利五行统一塞入相神栏。

| 项目 | 应记录的信息 |
|---|---|
| 格局用神 | 月令哪一十神，如何取出，有无变化 |
| 相神/救应 | 哪一干支做什么，使哪条路径成立 |
| 实际首需 | 扶抑、病药、通关或调候何者当前最切，需要哪一神 |
| 原局状态 | 已有且可用／已有受损／仅藏待引／缺而待运／尚未确定 |
| 忌与条件 | 谁破坏何处；什么情况下原来的喜转为过量、相碍或失用 |

不必硬凑每一栏。没有独立通关问题，就无需再指定一个“通关用神”。相同字承担多个职责时合并说明，避免制造五套喜用神互相打架。

## 综合排序：首需、辅助与条件性需要

不是按流派名称固定“格局永远第一”或“调候永远第一”，而是找**当前最先使主链无法发挥的障碍**。采用如下比较：

1. **先定资格。** 普通、从、化、专旺若未分清，先处理会导致喜用反向的节点；不把各分支的喜神相加。
2. **核验现成主链。** 哪一配置已经可用？若相神受伤便会使全链断裂，保护它通常比新增另一漂亮组合更切。
3. **查承受与气候门槛。** 日主无法承财杀、食不足制杀，或寒湿使生源火根难发挥时，必须先处理该门槛。气候已有适度配合，就不另抬为首需。
4. **比较药的净作用。** 每个候选都写改善哪处、损害哪处、是否有护药与替代。不能只累计好处，也不能因存在一点副作用就全盘排除。
5. **选一条可执行的主路。** 给首需、必要辅助、满足条件才用的候选；现有字是否足够与未来再增加是否有益分别论。两条互斥路径只能选主次或保留分支。

| 冲突 | 可以成立的处理 | 不成立的处理 |
|---|---|---|
| 食制杀与印生身冲突 | 食制已足则护食；身弱杀重且印有力时可转印化，按新链重评 | 印夺食后仍同时宣称原食制杀完整 |
| 印护官而财可生官 | 官源不足且财不坏印可并用；印为唯一救应时先护印 | 财能生官就忽略财已破掉护官印 |
| 冬金需火而金泄弱 | 保留有根火暖局，另需金土根援；火过强再克身须限量 | 把火暖局推出火为唯一用、金土永忌 |
| 夏木喜泄而已火炎木燥 | 水润木制过炎，保留适度泄秀；须水可用且不灭唯一火 | 水印一见就夺食，或调候水可以无限加 |
| 厚土需木而木生火再燥 | 有水润木、火不过量时木可疏；火已过旺时先核水与木去向 | 只写木克土，忽略木反生忌火 |
| 偏极顺势与逆势调候 | 先验逆势之神能否立足；可经顺势泄化改善时优先比较 | 见燥就投一点无根水，宣布调候完成 |

候选替代要逐项比较功能。丙与丁都可提供火气，但暖局、制金、合壬/合辛的结果不同；壬与癸都属水，承炎、润泽、合对象也不同。替代是完成同一职责的另一条路径，不是五行同类便等效。

### 最终结论写成有对象的喜忌

例如：“首需护住甲印以承杀生身，现有寅根可依靠；丙火兼暖并助承受，但增火前须防泄印过度。金财在能不伤甲的条件下才讨论，不能因能生水便列总喜。”

若首需原局未具，明确写“缺而待运”。若唯一药也有严重副作用，承认原局未完成救应，不拼凑成全美。喜忌随数量、根气、位置及岁运改变，不保证同五行所有干支同喜。
