# 相神：主链如何成立

## 先确定是哪一条主链

相神是全局成格所倚赖的关键辅助，可能生格神、护格神、制化不善之神，也可能合去妨碍、解冲取清。先说明格局准备怎样成立，再寻找相神；不能先挑一个喜欢的五行，事后把它命名为相神。

同一字可在月令格局口径下称相神，又在扶抑口径下称实际用神。输出时标明职责，不能因名词不同而认为出现两套相反结论。

禄劫另取用时，先区分所用之神与帮助它成立的相神，按 [术语口径](00-terms-and-methods.md) 命名。有两条竞争主链时，相神身份尚待各自条件确认；不能先把扶抑所喜称相，再用这个称呼证明该配法成立。比较办法见 [13-competing-configurations.md](13-competing-configurations.md)。

## 常见职责

| 已选成局路径 | 相神的主要职责 | 不能省略的条件 |
|---|---|---|
| 官格用财生官 | 财提供官的生源 | 财须可用；若另破所需印，不能只见生官就判有情 |
| 官格以印护官 | 印制伤、化官生身 | 须有实际伤病或承受需要；印过重泄官时另论 |
| 杀格食神制杀 | 食承担制杀 | 身、杀、食三者力量相称；杀轻制过或印夺食则路径受损 |
| 杀重用印化杀 | 印引杀气生身 | 印有力且不被财破；与食制杀并见须辨主次及冲突 |
| 印格身印旺而泄秀 | 食伤承接日主旺气 | 身能任泄，食伤未被印实际压制或合住；财再参与须另查是否坏印 |
| 印多取财损其过 | 财抑过旺之印 | 印根足、身能任财；印轻身弱时不得照用 |
| 食伤生财 | 财承接食伤 | 财有根气、能受生；不能因生财又党所忌官杀而仍称全美 |
| 禄劫另取官 | 财生官或印护官，依原局需要选 | 官可用，辅助能接上；印制伤护官不以身弱为唯一入口，须防重泄弱官；财印同见不自动双全 |
| 禄劫另取伤而生财 | 财承接伤气，或护住所需食伤的有效救应 | 先证明伤能泄、财能受生；只证有伤根不够判生财已成 |
| 官杀竞出而取清 | 实施有效合制的神作为救应 | 合制是否真正减少相碍须核验，不按字面删除被合之神 |

这是职责表，不强制每盘只有一个相神，也不强制每个喜神都叫相神。多字参与时指出首要辅助，再说明其他字的次要职责。

## 四项核验

1. **对象：** 它辅助哪一个格神或哪一条主链？
2. **效力：** 有根、有生源、得势或位置可达吗？藏而未透与明透清用分开。
3. **完整性：** 是否被克、合绊、损根，或救此处却在另一处致病？
4. **状态：** 原局已经具有并能用，还是仅有需要、尚待岁运补足？

格名成立而相神受伤，可以是成中有败；缺相而待救，不能说原局已成。相神也不能凭格名永久指定，例如印格并非永远以官杀为相，禄格并非永远以财为相。

## 成格之相、护相之救与一般喜神

三种职责分别标出，必要时由同一字兼任：

| 层次 | 判别问题 | 示例 |
|---|---|---|
| 成格之相 | 失去它，已选主链是否不能成立？ | 食制杀之食、财格生官之官、伤官佩印之印 |
| 护相之救 | 它是否主要解除相神所受破坏？ | 食被枭夺时制枭之财、印被财坏时制财之比劫 |
| 一般喜神 | 有所改善，但尚非主链不可少的节点？ | 已能任财后适量帮身，或已有暖气后的辅助火 |

“救神”与“相神”名称在不同用语中可能重叠；本包依职责区别，不强迫每盘三层俱全。反事实检查只是**移除其作用后重评**，不能真把其他关系全部固定：护枭之财失用，枭会恢复制食，杀的状态也要随之重算。

### 不同失用的后果

- 相神有字而无根、只有需要无实际作用：记待成，不判已成再破。
- 相神部分受制仍能任职：记有病或救而不尽；不把轻伤等同整格消失。
- 相神被合绊、冲根或克制到不能任职：指出主链断点，检查护相之救或另一主链。
- 救相之神引来新病：例如财制枭却又党杀，分别比较，不能只标救应成功。
- 岁运令原相失用、另一神接替：说明新链及新相，不能沿用原相的永久身份。

同一神与同五行多处根源分开：某透印被合，另一印仍有根能护官，不能称所有印尽失；某财干虚浮，但财支有力承食，不能忽略支中相神。

## 地支之相与相神受伤

相神不限天干清透。地支的有效会合可以引通、改变劫气去向，或通过牵制冲方护住所需之根。须说明具体支、所成作用及条件，按 [04-interactions.md](04-interactions.md) 检查，不以见合就解冲、见会就转气代替证明。

复核相神时，追问它失用后哪一条链会断：印本来制伤护官，印被财克或合绊后伤能否再攻官；食本来制杀，食根受损或被枭制后杀是否失去制约。这个失用后果决定其关键性，不能因日主反而得到一点生扶，就忽略原来的主链已经被破坏。

从格先定资格和所顺之势，再描述辅助职责。假从官杀带食伤之病，财若确能引食生官杀，可承担顺势救应；原局没有可用财时，写“所需救应未具”。普通身弱改用印化杀时，印又可能成为成局辅助。两种结论随主链选择，不能强行给同一字一个永久相神身份。

## 两种输出示范

- “正印格取食神泄秀，己土食神为成局相神；酉财承接食气，但不能据此认为财越多越好。”这里己也可称扶抑实际用神。
- “建禄另取壬官，酉中辛财为生官的主要相神；戊合癸若能取清，承担救应。官弱时还须核相神生官的实际力量。”不能把戊有合杀职责改成一切土都喜。
