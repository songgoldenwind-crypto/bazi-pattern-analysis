# 生克、合会与刑冲的作用核验

## 先看关系，再论结果

天干五合：甲己土、乙庚金、丙辛水、丁壬木、戊癸火。这里所列为**传统合化目标**，不是见两干就已经化成该五行。先辨是否相合、是否牵制所用之神，再查化神月令气势、根援、杂气与破坏条件。普通命局的两干有合，与日主进入化气格是两层判断。

日干本身参与的合，与其他天干之间的合分别核验。日主与所用官财相合，未成化时不能直接说官财被合没；仍须查向背、根气及效力。月时甲己中隔日干丁时，先查甲生丁、丁生己的通路，不能一见甲己就宣布印食全部合失。格局中的合不失用，也不保证调候效力完全不受牵制；两种职责分别核验。

地支基本关系：

| 关系 | 组合 |
|---|---|
| 六合 | 子丑、寅亥、卯戌、辰酉、巳申、午未 |
| 六冲 | 子午、丑未、寅申、卯酉、辰戌、巳亥 |
| 三合 | 申子辰水、亥卯未木、寅午戌火、巳酉丑金 |
| 三会 | 寅卯辰木、巳午未火、申酉戌金、亥子丑水 |

两支不齐全时只记录实际半合、拱会或趋向，不虚填缺字，再把虚填字当财官来成格。六合的化气与是否被三合三会改向也要另证，组合存在只是关系事实。

## 半合、成势与成化分开

- 三合三支齐全是组合完整的事实；是否足以改变月令主线、是否成化，仍查时令、透干、阻碍及全局去向。
- 含四正旺支的半合，如申子、子辰、寅午、午戌，可以助成相应气势。缺第三支，不等于完全不作用；未成完整三合，也不等于该旺势不能主导全局。
- 缺旺支的两端，如申辰、寅戌，不直接记成完整水局、火局；若相应五行透干有根、得势或有其他同气支援，可加强趋向。透壬癸不允许虚填一个子及其全部作用，透丙丁亦不能当作实有午支。
- 合会改变根援的实际去向，须逐根解释。不能从“半合有作用”跳到“支中异气一律消失”，也不能从“尚未全化”跳到“所有原根都保持足额作用”。

记录可写：“有子辰半合、透水及水根支持，水势增强；无申，不称申子辰三合齐全。辰内土木的效力另验。”是否从格仍看日主根援，不能只用局名裁决。

## 力量与位置

- 同一生克链看根气与位置，辨贴近、间隔、先后、是否有合绊或另一神截断。位置会改变结果，但不扩成“隔一柱一律完全不作用”的固定法律。
- 天干所透与地支所藏分层记录；不能把全部藏干当作同一层五个天干同时直接交战。藏干提供根、气和透出条件，具体作用还需全局说明。
- 不固定“先合后冲，见合忘冲”作为所有命盘的最高规则。查合的力量是否真的足以牵制冲方、会局是否完整、解冲后是否又损所需神。
- 冲可能损根、激发冲突或改变配合，不是字符消除。两强相冲、强冲弱、月令强根受冲、喜神忌神受冲，结果分别分析。
- 刑害不能凭关系名称直接推出伤残、犯罪或婚姻事实。与取格无关时无需展开神煞式叙述。

## 墓库的专门检查

辰戌丑未先是具体地支，内有不同藏干；“土受冲”与“其中水木火金根受冲”不必同向。按以下问题展开：

1. 所谓入库的是哪一五行/十神，它在原局是否透、是否有其他根？
2. 冲哪一个支，对本气土及关键藏气分别有什么影响？
3. 所需神会因此可用，还是反被损根；冲是否同时坏印、坏财、损官？
4. 若认为少量冲刑可引动所需藏气，说明该气此前为何难用、冲后为何可用，并核验是否同时受损；不把冲本身当成有利证据。

默认不推出“无冲不发”“冲库必发财”。同样也不推出“库永远不能冲”。

## 作用顺序与主次

同组官伤财印等十神，在不同位置可能形成不同路径。按具体根气、接续和阻隔解释先后作用，不能抽象成一套对所有干支适用的单向程序，更不能移植六爻的动静权限、日辰裁决到八字。
