# 喜忌相反的配法如何舍取

适用于同盘有两条实际候选、选择会反转喜忌的情形，例如泄秀与印制伤、食制杀与印化杀、财裁过印与财坏所需印。尤其禄劫另取用、伤印并透、藏官参与时，应先比较再定相神与综合喜用。只有一条明显有效的路径时不必制造对立，也不要求简单问答展示整张表。

## 先写各条路径要完成什么

对有原局依据的候选记录：

| 项目 | 核验问题 |
|---|---|
| 所保对象与所用 | 谁应完成什么任务？为何以它为核心，而不只是因为它透出、较弱或属传统善神？ |
| 成局辅助 | 谁承接、生护、制化或取清？明确所用神与相神，不先给喜神改名 |
| 实际病处 | 哪一作用已妨碍该任务，还是仅有关系、尚未造成实质破坏？ |
| 效力证据 | 有什么根源、时令、通路支持？有根、能发挥、足任任务分别回答 |
| 救后状态 | 去病后核心能否任职？药是否又泄弱官、坏必需印、灭唯一暖气等？ |
| 缺失条件 | 原局已有而可用、已有受损、藏而未清、须待具体岁运，还是尚不能排定？ |

两条路径用同样标准。不能用“有藏根”证明一条已经完成全部任务，又仅因另一条藏而未透就排除它。

## 常见竞争的决定节点

| 候选配法 | 成立所需的正面证据 | 不足以单独成立的理由 |
|---|---|---|
| 禄旺用食伤泄秀 | 日主能任泄，食伤实际可发挥，未因制合失用或严重破坏所需官杀等配合 | 身旺、有一食伤、火能暖局；泄秀成立也不自动等于生财成立 |
| 食伤生财 | 食伤可用，财有能承生的根气与通路，旺比劫未使财失用 | 支藏财、有相生方向，或未证财被夺；藏财未透不必否用，也不能冒充透财清用 |
| 印制伤扶身 | 食伤泄气确实超过承受，印能制伤生身，印与伤的程度合宜 | 有印有伤；或按字数把伤判轻、把印判重 |
| 印制伤护官 | 官为所用或救后确能任职，伤有实际妨官作用，印能减少此病且未重泄弱官 | 只见藏官；只见伤官凶神名；只见印合伤；身旺也不自动否定这条路径 |
| 财裁过印、护食伤 | 印确实压住所需食伤或造成其他明确障碍，财能约印而未坏必要救应 | 财属日主所克、财有土根、身旺喜耗；财同时生官杀及破印的损益须合看 |

制伤扶身与制伤护官可有重叠，但目的和成立条件不同。按扶身型佩印称谓论时保留其承泄条件；按护官论时先核官及伤的效力，不能偷换成“身不弱，所以印没有作用”。印的作用也有两面：制伤可以护官，官生印又可能泄弱官；印生身还会增比劫。净效果有利才能认作有效救应。

## 藏官、有根与隔位的具体限制

- **藏官：** 实际藏气可参与，不能以未透即无官；也不能把微弱藏官当成全局既定主用。说明它的根、生源、受伤和救后职责。伤与官同藏一支只是关系线索，不等于已证明伤官见官破格。
- **食伤根：** 有根与生源能支持候选，但须继续检查强印制合、寒湿及根的去向。不能把“不是浮火”推成“足以主用”，也不能只见强印就说食伤已灭。
- **藏财：** 能否承火、护火、约水分别判断。藏财受旺木制、未透、远隔或与其他合会争用时，不能同时满额计算各项职责；也不把未透当成完全无力。
- **隔位相生：** 中间有印生身、身生食伤的方向，是可引通的证据，不是已完成通关。须复核终点仍有多少制合、能否泄秀及暖局，不能以隔位宣布毫不相碍。
- **合的对象：** 印伤相合仍分别为印、伤；可以通过合伤存官起救应作用，但须所保官有效，不能把合伤本身当成官星出现或贵格已成。合化、合绊、减少干扰按 [作用核验](04-interactions.md) 分别判断。

## 选择主次，不把喜忌相加

1. 先处理普通与特殊格资格，再比较有实际依据的配法。不同资格下的喜忌不能直接相加。
2. 优先采用核心及辅助已经可任职、主要矛盾有有效处理的路径，不能把须新增关键神的设想写成原局已成。既有一字不等于既有整条主链。
3. 对候选分别说明净作用，比较哪一条需要的额外假设较少。受损而剩余效力仍够任职，可判有病而可用，不要求药毫无副作用。透藏、旺衰、暖润和传统善恶名称都不是单项裁决器；不设固定权重或“有官永远先护官”的顺序。
4. 有决定性依据时给主判，并点出另一条的具体断点。不能因两路名称都存在就永久回避主判，也不能为给主判而虚造效力。
5. 效力仍不能排定时，保留导致取用反向的具体节点和两支条件。说明已确定的月令、根援与结构关系，不输出一张确定的总喜忌表，也不把所有字都列为喜神。

例如，取印制伤护官时，财能破坏关键印才成为病；财若同时能引伤生官，仍须比较是否真可接替原救应。取伤生财时，财能接续且不坏必需印才为助。不能从“财克印”或“土能约水”直接决定整柱岁运的吉凶。已给岁运的变化按 [08-luck.md](08-luck.md) 执行。

## 对照解释与重问

先比较格局对象、配法条件、作用效力，再谈术语差异。新解释提出遗漏的路径时，检查它，不因维护旧结论排除；用户偏好某解释，也不等于该解释已被证实。修正须指出新发现的跳步、遗漏关系或新增事实，而不能只从“原判不充分”跳成“另一判已正确”。

若资料指定采用某一种取格或顺逆口径，明确新增假设，并在该口径下给结论；不把方法选择冒充四柱已证明的事实。人物身份、已知经历和由这些经历反推的时辰，不能充当两条命理路径的独立验证。未确认时柱的个案，只对给定四柱作条件分析，不把取象、刑害或善恶名称直接转为现实行为定性。
