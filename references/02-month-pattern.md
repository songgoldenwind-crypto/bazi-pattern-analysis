# 月令取格、取清与主次

取格回答月令之气通过什么配置主事，成败另见 [03-success-failure.md](03-success-failure.md)。所喜之神不必就是月令格名，不能用最终喜用反推月令。

## 一、列候选，再舍取

先写月支实际藏干、本气、各藏气在天干是否出现及有无根援，再查月支参加的合会。藏气同五行异阴阳透出，可记该气得到引出，但正偏名称仍以实际透干为准，不把本来没有的藏干填入支中。

| 月令情况 | 默认处理 | 必须排除的误推 |
|---|---|---|
| 本气透出，未受有效改向 | 以本气为首个主格候选，再验配置 | 本气透便必成格、必为喜 |
| 本气不透，余气独透 | 余气得根、能主事时可取该透神；本气背景仍保留 | 本气永远压过余气，或透一个字就无视全局 |
| 本气、余气都不透 | 先用月令本气作背景候选，说明藏用未清；看他柱能否配合 | 未透就没有月令格，或补造司令 |
| 多神并透 | 分别找可成立的链；相生有情可配用，相碍须制合取清 | 一律叫杂格，或一律算多格都成 |
| 月支参与有效合会 | 比较透干、时令、根势及原气去向，再决定变格、兼用或仅增势 | 见半合就整支改五行，见三合齐全就删尽异气 |
| 月令为比劫、禄刃 | 以此为背景，另取财官杀食的有效配法 | 把禄刃当可直接顺生的财官印食 |

阴阳名称来自日干关系。甲寅为建禄，甲卯为月劫兼阳刃；丁午为建禄，不称阳刃。五阳刃采用甲卯、丙午、戊午、庚酉、壬子；阴干不另套一套阳刃表。

## 二、多透如何定主格、兼用

1. **同源而相成：** 官印相生、财生官、食生财等可组成一条主链，不必互斥。说明月令取谁、另一神承担什么；“兼用”不是把两个格名并列就结束。
2. **有克而有用：** 食制杀、财损过印可以是有情配置，不能只因相克就取清删一方；须检查力量和承受条件。
3. **争克妨碍主链：** 官伤同透、财坏所需印、枭夺所需食等先判冲突能否到达。有效合制可取清；名义有救而无力，仍不能称清。
4. **官杀并透：** 比较月令来源、所留者的根势以及合制能否留一条可用主链。不固定“去杀留官”或“去官留杀”；杀轻官重与杀重官轻的救应可能不同。
5. **选主链的依据：** 月令联系直接、核心神有根可用、辅助能接续、矛盾得到处理。未被选中的链注明是辅助、受制、尚缺条件或与主链冲突，不将所有名称一并判成。

禄劫伤印并透，或藏官与泄秀会导致喜忌反向时，按 [13-competing-configurations.md](13-competing-configurations.md) 比较后取用；透藏不能代替效力裁定。

## 三、杂气辰戌丑未

四支以土为本气，又有各自余气、库气；“杂”指可取之气不一，不等于混乱失败。

- **透干取清：** 甲辰透戊可取财，透癸可取印，透乙则属劫的配法；具体仍验各自力量。透财印相碍，不能仅因都从月令来就称双美。
- **会支取清：** 辰会申子而水势有效，可转印、水相关主线；透干与会支可共同支持，也可相互冲突。
- **透会相成：** 丙辰癸乙并透，可比较官生印、印护官的链；若乙弱受损不能担任职责，格名联系仍在而配合不足。
- **透会相克：** 壬未透己官而会亥卯未木伤，须核伤是否攻官、是否有财印引通；不能说两者都是月令所出就自动有情。
- **有克反成配合：** 丙辰透戊食与壬杀，若身食杀相称，可取食制杀；癸辰透戊官而水势增强，可比较官制劫，不能只因克水就否定。
- **未透而冲库：** 冲不代替透清。分别核验土本气与内部木火金水的增损，不把冲辰必出水、冲未必出木作为规则。详见 [墓库检查](04-interactions.md)。

## 四、合会是否真的变格

月支加入新势，按三个层次报告：**仅助势**、**另一气参与主事**、**主链确已改向**。例如印月会比劫，原印仍透而能生身时，可保留印的来源；不能一见会局便把原印一律注销。比劫参与财局或食伤局，也须证明其实际去向改变，不能凭局名宣布劫已化财。

月令被冲首先是关键根气与配置受扰，不等于换成冲方的月令。原局取格与岁运暂时成变分开，见 [08-luck.md](08-luck.md)。

## 输出取格的最低信息

写明“月令何气 → 实际透会 → 主格/配法 → 舍弃另一候选的理由”。如：“辰月癸官透而乙印相承，以杂气官印为主链；戊食藏而未形成有效制杀路径，暂不另立食格。”若候选尚不能分主次，指出决定点，不能以含糊的‘综合格’代替舍取。
