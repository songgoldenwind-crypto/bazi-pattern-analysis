# 各格成立、破坏与救应

先按 [月令规则](02-month-pattern.md) 定背景和主链，再检查本文件。格名成立、配法成立、配合充分是三个层次；身弱不必破格，身旺不保证成格。各条都是候选路径，须依 [力量](01-chart-and-strength.md) 与 [位置作用](04-interactions.md) 核验。

## 正官

| 配法 | 成立条件 | 失败与救应 |
|---|---|---|
| 财生官 | 官需要生源，财有根，身能承官 | 财又破唯一护官印，或官已太重身轻，则不能继续滋官；可比较印承官生身，但须护印 |
| 印护官 | 官为实际所用，有伤攻官而印能制合伤，或身轻需印承官生身；两种职责分别核验 | 财坏印、印合绊后伤再攻官，或印过重泄弱官；可制财、护印或比较财引伤生官，不能只写见印即救 |
| 财印并用 | 财、印各有职责且位置、力量容许各用 | 财印贴战或相合失辅，可成孤官；有一枚印被损而另一枚仍有效，不一概全败 |
| 官杀取清 | 合制减少争杂，所留官有根可用 | 所留反弱、合去主神或救神受伤；重官过多也需裁减，不以多官为多贵 |

官伤同见须证明直接相碍。财能引伤生官、印能制伤时可能救应；救者受损或通路不足则救而不尽。日主合官不直接视作官消失。

## 财

- **食伤生财：** 身能任泄、食伤能发挥，财有根可受生。财食已重身轻，印比可助承受；财食轻而比重，反须助食财，不照搬身旺喜财的单句。
- **财生官：** 身财官力量相宜；财党过旺之杀、官泄轻财、身轻不能承载时转为病。不能把任何财官并见都当成链已成。
- **财佩印：** 财重身轻需印，或其他明确职责；财印不相碍、印能生身才可配用。印轻被旺财所破，不能只按“有印护身”论成。
- **财逢比劫：** 食伤引比生财、官杀制比、有效合制可救。弱财直接遭劫而无引通，仍有病；食伤同时生忌杀时要比较得失。
- **财带杀：** 食制、合杀或印化须至少一条有效；财破印、泄食再生杀会损救应。所用官杀的正偏及所留对象须交代。

财根多而不透，可有财气但未清用；透一财而根足与财多浮露不相同。

## 印

- **官杀生印：** 印需要生源、身有承生需要，官杀之气能由印转生日主。身印都重，再生印可能壅滞；不能印格永远喜官杀。
- **身印旺而食伤泄秀：** 日主能任泄，食伤有效且未被印压住。印旺身弱、食伤又重时不可只凭印多称身旺泄秀。
- **印多取财：** 印根深、身能任财，财裁过印而不毁必需的生源。印浅身轻财旺，为财坏印；比劫制财、合财或其他护印需实际奏效。
- **印兼食财：** 食有泄秀需要，财另有裁印或承食之需，三者位置及力量可协调才成立。财会反生杀、食生财又破轻印时，不判全美。
- **正偏印并见：** 先看功能和去向；偏印只有实际克夺所需食神才成枭夺食。官杀并见亦须看取清，不按数量宣布杂败。

## 食神

- **食神生财：** 身能生食、食有根源、财可承接；旺食泄弱身或财又党忌杀时，不成完整善链。
- **食神制杀：** 日主能承泄，食有力可制，杀确有制约需要。杀轻食重为制过；身弱杀重而食弱，不能把存在克杀关系当制伏已成。
- **枭夺食：** 确认印实际妨碍所需食。财能制枭是救应，但财又泄食生杀时可能救此害彼；只靠有财的字面不足。
- **食杀印并见：** 先选食制或印化主线。食太强、杀较轻时，印裁食可能护杀；身弱杀重时印可接替食制。原食制已适度，印再夺食则破原链。
- **气候例外：** 夏木食火过旺，水印可润木制炎；冬金食水过寒，火有调候职责。都须解释为何不构成实质夺食，不能扩成食神一律喜印。

## 七杀

| 配法 | 要核验的条件 | 失效或转路 |
|---|---|---|
| 食神制杀 | 身可承泄、食杀相称、制杀能到达 | 杀轻制过可护杀；枭夺食或财泄食党杀须救 |
| 杀印相生 | 杀重或身需扶，印有根能承杀生身 | 财破印、印合住、印过强泄尽轻杀；需要时改护印或比较其他路径 |
| 刃/比抗杀 | 身方根援有效，与杀力量可相持 | 刃杀一方过量，仍需制化；无食时不能凭空套“印夺食” |
| 合杀取清 | 有效合制减少杀的干扰，所留主神可用 | 日主自合、争合、合而仍有根用皆另验；不能字面删杀 |

财不固定为杀格之忌。杀轻制过时财可滋杀；杀重食弱时财可能更坏。位置能改变财生杀、食制杀的先后去向，仍须根势支持，不能单凭隔位保证相安。

## 伤官

- **伤官生财：** 日主有承泄能力、财能受生。身轻伤重再生财耗身，先需根援；财再党杀要另验。
- **伤官佩印，制伤扶身：** 伤旺、日主承泄不足，印有力制伤生身；伤是否过量、印是否有根分别判断，不能只数伤官个数。伤轻身旺而印重，可能反压所需泄秀；财破唯一佩印时原链受损。
- **印制伤以护官：** 官为实际所用或有可恢复的成局作用，伤确实妨官，印能制合伤而保官。此职责不以身弱为前提；同时比较印生身、泄官、损失必要泄秀的副作用。不能把扶身型佩印的条件移来一票否决，也不因官伤印齐全便判护官已成。
- **伤官用杀印：** 杀气可由印化、印能兼制伤，才能协调；财若坏印党杀，不能只看财生官杀为美。
- **伤官与官：** 直接相克且官为关键才论伤官见官之病；财引伤生官、印制伤护官需逐条验。藏伤透官与伤官同透的直接程度不同。
- **金水伤官用官火：** 寒金水盛，火有暖局需要，财印等须使官火能立。火虚浮受水压制、日主泄弱又无根，不能仅凭调候宣布官火已为主用。
- **财印并用：** 各有明确需要且能分任职责，不相碍才可。不能看见伤官、财、印就一律称高配。

## 建禄、月劫

禄劫是背景，须另择有效主链：

- **用官：** 官要有根与生护，财生官、印护官依需要选；孤官被伤或合住，需救。藏官可列候选，但须说明根源、受生、受伤及救后能否任职，不能以未透直接排除，也不能当成已清透。身有禄不代表官可无限增加。
- **用财：** 比劫重而财轻，通常需食伤引通；财根足且透清也须查是否受夺。财食重而身承受不足时，可以印比帮身，不固定劫禄都忌印比。
- **用杀：** 查食制、印化或根比抗杀，明确所选路径；杀轻食重与杀重食轻所需相反。
- **用食伤：** 日主能任泄、食伤有实际效力且未破坏已选关键配合，可取泄秀；若进一步称生财，须另证财能接续。印实际压所需食伤则病，印制过量泄气或护所用官则可能为助，须先分职责。
- **合会转向：** 比劫参与财局、食伤局可能改变去向，须证明有效成势，不凭组合名称宣告比劫已尽化。

同盘几条路径对印、食伤、财的喜忌相反时，不能凭身旺或透藏单项先作选择。详见 [竞争配法的比较](13-competing-configurations.md)。

## 阳刃

阳刃强，官杀有根能制，且刃杀力量相宜，才成制刃路径。财可生所需官杀，印可化过杀生身，均须有实际需要。

官杀太轻、被食伤制尽或被合绊，则制刃失用；官杀太强、刃根受损，则需印比支持或食伤裁过，不能无限加杀。刃用财须财有根且有食伤引通，不能让弱财直接承受旺劫。月支会局改向时重审，如戊午会旺火后印气主事，不能始终套土刃喜杀。

## 成败与救应的最终状态

| 状态 | 判定含义 |
|---|---|
| 配合成立 | 核心职责可完成，关键力量与通路相称 |
| 成中带败 | 主链可用但另有实际破坏，须点名病处 |
| 败中得救 | 原病存在，救应有效且未造成更重的新病 |
| 救而不尽 | 救神弱、受伤、距离受阻或只救一处，尚不能称尽清 |
| 相神受损 | 原先成立的关键辅助失用，须回查哪一环断裂 |
| 待救未成 | 只提出所需，原局尚不具备；未来岁运补到仍须复核 |
| 路径改换 | 原链失效而另一链真正成立；按新链重新取用，不保留原链全部赞语 |

每次记录“病在哪里 → 谁来救 → 凭什么救得动 → 是否另致病”。格局状态是传统方法内的结构评价，不转写成财富级别或人生结果。
