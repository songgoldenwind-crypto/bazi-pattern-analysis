# 原局、大运与流年的成败变化

只使用用户或外部排盘已给出的运柱、流年及时间范围。本包不计算顺逆、起运或排运。原局判断无需岁运；未给出的年份、运序不补造。

## 三层状态分开

- **原局基线：** 月令主格、配法、相神、力量、气候、已有病和待救条件。
- **某运组合：** 运干运支加入后，支持、损根、取清与制化如何变化；不是永久改写出生月令。
- **该运某年：** 在运背景下再核流年，指出哪一作用增强、受阻或短时改向；不能只用原局喜忌表给年贴标签。

## 逐柱执行流程

1. **列职责。** 运干、运支分别带来哪一十神、根、源、合冲；整柱有无盖头、截脚、互相得根，先不判十年皆吉。
2. **优先查主链。** 格神、相神、护相之救是否得根透清、被合克、冲损或反助病神。
3. **重评力量。** 日主与关键神哪个相对增强；喜神到来是否足以任职，不只看所属五行。
4. **查新关系。** 争合、合冲同见、局方补齐、藏气透出，按 [作用核验](04-interactions.md) 判结果，不能字面删改干支。
5. **查主链改换。** 原局待救是否真正完成？原食制是否被印夺，印化能否接替？原从局是否去病或恢复根援？
6. **叠加流年。** 与原局及运同时比较，不能只令岁运互相作用后便忽略原局，也不把每个关系当全额独立。
7. **更新喜用。** 保持、补强、过量转忌或换路径，各说明理由和适用期间。某年现病不等于全运皆败，运主路有病亦可能年暂救。

不固定前五年只看干、后五年只看支。用户指定分段法时说明额外假设，仍核整柱。也不规定流年可无条件删除大运，或大运自动压倒流年所有作用。

## 成变的常见入口

| 加入因素 | 可以促成 | 同时要防 |
|---|---|---|
| 所需神得根 | 浮印能化杀、弱食能制杀、火能暖 | 根同时被强冲合走；增强过量而夺食泄官 |
| 月令藏气透出 | 杂气取清、原局待用得到表达 | 透出者正是伤官攻官、财坏印等病神 |
| 方局补齐或被扰 | 某势主事、改变根气去向 | 补齐不保证成化；原相根被改向或另一组合争支 |
| 合去干扰 | 官杀取清、护住所需相神 | 合掉的反是主神；争合、合而仍有用须另验 |
| 冲动关键支 | 减病、破合、改变根援 | 拔掉唯一所需根、引动忌气；不按冲库必发 |
| 药增强或被护 | 原局败中得救 | 药又另致病，救而不尽；过量后主次倒置 |

## 同五行仍会不同

- 丁日用壬官：丙帮身与丁帮身都属火，但丁还参与合壬，须核官能否任职。
- 甲日用辛官：申酉可能增官根，庚到则另带七杀；不能都简写金运同喜。
- 丙日用子亥水：丙丁帮身与巳午火根不同，巳亥、子午冲会影响原水、火根，不能只论增火。
- 原局用甲疏土：甲寅、甲申的根援与冲合背景不同，乙亦不自动代替甲的全部材性职责。

## 特殊格岁运

- **假从去病：** 从杀带弱食时，财若能引食生杀可减病；财无根受制不能宣称引通完成。
- **根援恢复：** 浮印到运得根、能化杀生身，须重审普通身弱路径。只见印干未能立足，不必然破从。
- **从儿变化：** 财得根可完整顺生；强印能夺食或官杀令食财争战时，查是否退回普通配置。
- **专旺变化：** 逆神有根源且确能立局，重审资格；一弱逆字只可能残病。顺势神增加也可能泄过、太寒燥。
- **化气变化：** 助化、去余根可促清，恢复原气或有效损化神可破化；不凭现实走运结果倒推原局资格。

## 输出方式

用“原局已有/待救 → 运带来的机制 → 年的增减 → 当前成败、相神与喜忌变化”组织。完整演练见 [命例](12-worked-cases.md)。无提供岁运的原局案例，不自加大运当作人生事实。

结论只说明传统规则下的结构变化。没有现实证据，不由冲合直接断具体亲属事件、财富数额或应验日期。
